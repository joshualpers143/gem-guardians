📲 Install & Game Information

Everything about installing, updating, offline play, and keeping your progress. This guide is separate from the QOL update history.

How to Install Gem Guardians on Android (Brave / Chrome)

  • Public game website: https://joshualpers143.github.io/gem-guardians/. Open this HTTPS link on your Android phone in Brave or Google Chrome, and wait for the game to load.
  • In Brave: tap the three-dot menu (⋮), choose Install app or Add to Home screen, and confirm. In Chrome: tap the three-dot menu (⋮), choose Install app or Add to Home screen, and confirm. The exact wording may vary by browser and device.
  • Find the Gem Guardians icon on your home screen or in your app drawer, then tap it to play. If you only see Add to Home screen, it may create a shortcut instead of a standalone app.
  • After a successful first online load and caching, the game can be played offline. Open the game online after an update so the latest files can download before going offline.
  • To publish future Public Edition updates, upload the updated website files to the same GitHub repository (gem-guardians), replacing the existing files without changing the website address or the saved-data key. Do not upload Creator Edition files to the public repository.
  • Progress automatically saves locally in the current browser or installed app every five seconds and on app hide/exit; you can also press Save. Test by making progress, pressing Save, reopening the game and checking that progress remains.
  • Old downloaded HTML files, Brave, Chrome, other phones, and the Creator Edition may use different storage. Saves do not automatically sync or transfer between them. Keep old files, and do not clear browser/site data or uninstall the app if you need its local progress.
  • If Install app is missing, try Add to Home screen, reload the HTTPS page, or open the link in Chrome. An installed shortcut does not necessarily guarantee full offline/PWA behavior.

Important: Installing Future Game Updates & Keeping Your Progress

  • Every new Gem Guardians update must be loaded to receive its new features and fixes. Open your installed game while connected to the internet, then close and reopen it if needed to activate the latest update. You normally do not need to uninstall or reinstall the app.
  • Your game progress is designed to stay saved across updates on the same installed game and browser, including your units, gems, levels, and other progression. Updates preserve the same website address and save keys.
  • Important: Progress is saved locally on your device, not in an online account. Clearing browser/app data, uninstalling, changing browsers or devices, or a storage failure may erase it. Updates cannot guarantee recovery from those events.
  • Always use the official Public Edition website: https://joshualpers143.github.io/gem-guardians/. Do not download a separate HTML file for each update.
  • If a new feature does not appear, connect to the internet, open the game website, refresh once, then fully close and reopen the installed game. Avoid clearing site data, as this may delete progress.

Installable Offline PWA & Stable Saves

  • Install Gem Guardians from a stable HTTPS web address; game code is cached for offline play after the first visit.
  • Progress is saved to this edition's browser storage automatically every five seconds, on app hide/exit, and when Save is pressed. The previous valid save is retained as a local backup.
  • Future releases must replace the files at the exact same HTTPS origin and deployment path and keep the save key unchanged (gemGuardiansSave); save migration reads older supported fields without wiping progression.
  • Creator and Public are separate installations and save keys; neither accesses the other's data.
  • Opening a previously downloaded local HTML file uses a different storage context. Its save cannot automatically migrate into this PWA. Do not delete old files or browser data until your old progress is recovered.
  • Offline saves are local to the browser/app; uninstalling, clearing site data or switching browsers/devices can erase or hide progress. This is not cloud sync.
