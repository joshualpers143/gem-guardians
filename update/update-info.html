New Feature

Restart Map Button

Implemented Monday, October 12, 2026 at 11:04 AM MDT

  • New ↻ Restart Map button in the battle controls, including fullscreen. No more playing out a bad run until you win or lose.
  • The game asks first, right on the battle screen, so fullscreen stays on. The battle pauses while it asks.
  • A restarted run gives no rewards (only finishing or losing a map does), so restarting cannot be used to farm gems or EXP.
  • The map starts fresh from wave 1 with your starting coins. Your battle speed and Auto Play stay on.
  • In Infinite Mode, use End Run to keep your rewards. A ranked leaderboard run that is restarted does not count; the new run starts a new one.
New Feature

Online Features Lock When You Are Offline

Implemented Monday, October 12, 2026 at 11:04 AM MDT

  • When the game cannot reach its server, a 📴 Offline badge appears and every online feature locks: Cloud Save, choosing a player name and Leaderboards. Future online features (shop, events, codes) use the same lock.
  • The game checks the real connection itself, because a phone can say it is online on Wi-Fi with no internet.
  • Gameplay and saving on this device keep working normally offline.
  • When the connection comes back, everything unlocks by itself, your cloud backup runs and any waiting leaderboard result is sent.
  • Leaderboard runs that start offline never count. A ranked run that loses its connection midway is sent when you are back online; the server times every run, so going offline cannot help a score.
Bug Fix

One Secret Unit per Banner

Implemented Monday, October 12, 2026 at 11:04 AM MDT

  • The summon banner showed all three Secret units at once. Now each banner features one Secret unit, and it rotates every refresh (every 5 minutes) between Abyss Summoner, Rift Blade and Chrono Warden.
  • Secret pulls (0.5% from Player Level 10, guaranteed by 2,500 pulls) give the featured Secret unit, just like the other rarities.
  • Odds and pity are unchanged.
