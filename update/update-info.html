Name Changes Are Checked Online

Implemented Monday, October 12, 2026 at 3:22 AM MDT

  • Every name is checked online. To choose or change your player name you must be signed in to Cloud Save and connected to the internet, so the game can confirm that nobody else already has it. Names can no longer be changed offline.
  • If you are offline, the name screen says so instead of letting you pick a name that might already be taken.
  • Tapping Sign in to change in your Profile takes you straight to Cloud Save.
  • Leaderboards (coming soon) require a claimed player name. Players without one will be asked to claim a name before they can join.
